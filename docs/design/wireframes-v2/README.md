# RideSync wireframes v2 (rider and admin)

Low-fidelity wireframes for the current app: the sign-in homepage, the rider view and the admin view, each at laptop width (1440 px) and mobile width (390 px). They replace the older single-view drawings in [../wireframes.html](../wireframes.html), which still describe the first six-screen version.

Figma file: https://www.figma.com/design/qIJL5tWhZNS8OFYAXtXecg (RideSync Wireframes v2 (Rider and Admin)). The file is the editable source; the PNGs here are 1x exports of its frames.

Orange dashed boxes in the images are annotations, not part of the UI.
